# One-Line Fridge Roast

A single-line roast of my stainless-steel fridge, written to be read aloud in one breath: it keeps every fingerprint, so it doubles as the only witness to whoever keeps stealing my leftovers.

## Run

```sh
node main.ts
```

This writes the roast to `/output/entry.txt` (exactly one line, no trailing newline).
